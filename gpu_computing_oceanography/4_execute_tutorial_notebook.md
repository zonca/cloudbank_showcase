# 4 - Execute the Tutorial Notebook

Goal: Learn how to execute the ocean modeling tutorial notebook in either Jupyter Browser or VS Code, and how to verify that the GPU is correctly detected and utilized.

## Step 1: Open the Notebook

Depending on which method you used to connect to your GPU instance, open the `ocean_gpu_tutorial.ipynb` notebook.

### Using Jupyter via Browser (from Tutorial 2)
1. Ensure your Jupyter server is running and you have connected via your browser.
2. In the file browser on the left, navigate to the `gpu_computing_oceanography` folder.
3. Double-click `ocean_gpu_tutorial.ipynb` to open it.

### Using VS Code Remote (from Tutorial 3)
1. Ensure you are connected to the server via VS Code Remote SSH.
2. In the Explorer view on the left, navigate to the `gpu_computing_oceanography` folder.
3. Click on `ocean_gpu_tutorial.ipynb` to open it. Make sure you select a "Julia" kernel when prompted.

## Step 2: Run the Notebook and Verify GPU

### 1. Initialize the Environment
Click on the first code cell and run it (Shift + Enter).
```julia
using Pkg; Pkg.activate("."); Pkg.instantiate()
using Reactant, Enzyme, CUDA, MPI, Oceananigans
using Oceananigans.Architectures: ReactantState
include("ocean_utils.jl")

MPI.Init()
CUDA.versioninfo()
```

### 2. Verify GPU Detection
Once the first cell finishes executing, look closely at the output generated by the `CUDA.versioninfo()` command.

**How to verify everything is working:**
* **CUDA Toolchain**: It should list the runtime, driver, and compiler versions (e.g., driver 535+).
* **Julia Packages**: It will show versions of `CUDA.jl` and related GPU packages.
* **Device**: The most critical part is at the very bottom. You should see `1 device:` listed, followed by details of the GPU.
  * **Expected:** `0: Tesla T4 (sm_75, 14.576 GiB / 15.000 GiB available)`
  * If it says `0 devices` or there is an error, the GPU is not correctly attached or the drivers are not installed. Double-check your Google Cloud VM configuration and initialization steps.

## Step 3: Execute the Simulation
Proceed to run the subsequent cells in the notebook.
* The notebook will set up a grid and configure the ocean architecture.
* It will initialize the variables (e.g. `Nx=48`, `Ny=96`, `Nz=32`).
* You'll observe output detailing the time steps and simulation progress, taking advantage of the GPU.
* The final cell will visualize the results (e.g., "Surface Temperature" heatmap) using CairoMakie, confirming the simulation successfully executed and produced data.
